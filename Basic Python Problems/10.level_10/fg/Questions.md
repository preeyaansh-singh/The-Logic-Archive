# Topic 1 — Basic Nested `if`

## Q1. Positive Number and Even/Odd

Write a Python program that takes an integer.

- First check whether the number is positive.
- If it is positive, check whether it is even or odd.
- If it is not positive, print `Not Positive`.

### Test Case 1

**Input**
```text
14
```

**Output**
```text
Positive Even
```

### Test Case 2

**Input**
```text
15
```

**Output**
```text
Positive Odd
```

### Test Case 3

**Input**
```text
-8
```

**Output**
```text
Not Positive
```
