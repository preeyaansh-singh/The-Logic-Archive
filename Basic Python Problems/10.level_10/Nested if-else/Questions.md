# Topic 2 — Nested `if-else`

## Q5. Positive, Negative, or Zero with Even/Odd

Write a program that takes an integer.

- If the number is positive:
  - Check whether it is even or odd.
- Otherwise:
  - If it is zero, print `Zero`.
  - Otherwise, print `Negative`.

### Test Case 1

**Input**
```text
12
```

**Output**
```text
Positive Even
```

### Test Case 2

**Input**
```text
7
```

**Output**
```text
Positive Odd
```

### Test Case 3

**Input**
```text
0
```

**Output**
```text
Zero
```

### Test Case 4

**Input**
```text
-9
```

**Output**
```text
Negative
```
